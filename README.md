# Сайт медицинских услуг «Здоровая жизнь» (ООО «Здоровая жизнь»)

Дипломный проект: Сайт для автоматизации записи пациентов на диагностику, ведения прайс-листа услуг клиники и онлайн-выдачи результатов медицинских обследований.

## 🚀 Основной функционал

- **Личный кабинет пациента:** отображение персональной медицинской карты, динамическое отслеживание статусов приёмов («Запланирован», «Завершен», «Отменен») и безопасное скачивание результатов исследований (PDF / Изображения).
- **Система онлайн-записи:** интерактивный выбор направления, врача и времени приёма с автоматической подстановкой выбранной услуги с главной страницы.
- **Интеллектуальный подбор по симптомам:** интерактивная форма обратной связи на главной странице для консультации с дежурным специалистом.
- **Панель администратора:** управление структурой направлений, базой данных медицинского персонала и архивом обращений.
- **Безопасность данных:** сквозное хэширование паролей по стандарту PBKDF2/SHA-256, встроенная защита от SQL-инъекций, CSRF и XSS атак. Секретные конфигурации полностью изолированы в переменные окружения.

## 🛠 Технологический стек

- **Backend:** Python 3.11+, Django 5.x
- **Database:** PostgreSQL 15 (развернута в изолированном Docker-контейнере)
- **Frontend:** Чистый семантический HTML5, кастомная адаптивная верстка на CSS3 (Flexbox, Grid Layout) — *100% независимость от внешних CDN библиотек*
- **DevOps:** Docker, Docker Compose
- **Качество кода:** Flake8 (PEP8), Mypy (строгая статическая типизация)
- **Тестирование:** Django TestCase (написано 18 комплексных Unit-тестов, проверяющих бизнес-логику и защищенность маршрутов)

## 📦 Инструкция по развертыванию и запуску

### 1. Подготовка окружения
Клонируйте репозиторий и перейдите в корневую папку проекта:
```bash
git clone https://github.com/MajorDiana2003/medical_diagnostics.git
cd medical_diagnostics
```

Создайте локальный файл конфигурации `.env` на основе примера:
```bash
cp .env.example .env
```
*Заполните сгенерированный файл `.env` своими секретными ключами и доступами.*

### 2. Запуск базы данных в Docker
Убедитесь, что у вас запущен Docker Desktop, и поднимите контейнер с PostgreSQL:
```bash
docker-compose up -d
```

### 3. Настройка виртуального окружения Python
Создайте и активируйте виртуальное окружение, затем установите зависимости:
```bash
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для macOS/Linux:
source venv/bin/activate

pip install -r requirements.txt
```
*(Примечание: если requirements.txt еще не создан, установите вручную: django, psycopg2-binary, django-environ, flake8, mypy, django-stubs)*

### 4. Применение миграций и создание администратора
Создайте структуру таблиц в базе данных и зарегистрируйте суперпользователя клиники:
```bash
python manage.py migrate
python manage.py createsuperuser
```

### 5. Запуск тестов и линтеров
Для проверки работоспособности выполните автоматические тесты:
```bash
python manage.py test
```
Отчет о покрытии можно вывести в консоль командой:
```coverage report``` -  Покрытие состовляет 93%

Также отчет о покрытии есть в html-файле:
```htmlcov\index.html```

Flake8 и mypy проходят без ошибок

### 6. Запуск веб-сервера

```bash
docker-compose up --build
```
Сайт будет доступен по адресу:[ http://localhost:8000/ ]
Панель управления:[ http://localhost:8000/admin ]
